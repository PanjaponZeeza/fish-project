# FishDB: AI Northern Thai Fish Identification Platform 🐟🤖

โปรเจกต์ระบบจำแนกชนิดปลาน้ำจืดลุ่มน้ำภาคเหนือด้วยปัญญาประดิษฐ์ (AI) พัฒนาเพื่อการศึกษาความหลากหลายทางชีวภาพ

## 🌟 Key Features
- **AI Scanner**: วิเคราะห์ชนิดปลาผ่านกล้องและรูปภาพอัปโหลด
- **Fish Encyclopedia**: สารานุกรมรวบรวมข้อมูลปลาเชิงลึก
- **High Performance API**: พัฒนาด้วย NestJS เพื่อการจัดการข้อมูลที่รวดเร็ว

## 🛠 Technology Stack
- **Frontend**: Next.js 14+ (App Router), Tailwind CSS
- **Backend**: NestJS, MongoDB
- **AI Model**: TensorFlow.js / Teachable Machine
- **Language**: TypeScript

## 📂 Project Structure
- `/frontend`: ระบบส่วนหน้าและการเชื่อมต่อ AI Model
- `/backend`: ระบบจัดการข้อมูลและ API
